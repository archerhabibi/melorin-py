# Documentation policy

Current operational guidance lives in `README.md`, `README.fa.md`, `docs/RUNBOOK.md`, and the current release evidence matrix. Phase reports and historical completion notes belong under `docs/history/`; they are evidence, not active instructions.

When a setting, route, install step, or security rule changes, update the English and Persian README plus the runbook in the same change. Do not store tokens, passwords, TOTP seeds, age identities, or provider credentials in reports.
