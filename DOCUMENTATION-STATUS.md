# Melorin Documentation Status

`docs/RELEASE-EVIDENCE-MATRIX.md` is the sole current release-status source.
It contains the J01-J19 remediation table and remains fail-closed until
runtime and production evidence exists.

The numbered `docs/01` through `docs/11` files are requirements and design
references. `docs/12-Change-Log-v1.1.md` records accepted changes,
`docs/API-IMPLEMENTATION.md` is the current route map, and `docs/RUNBOOK.md`
contains operational procedures.

`F*.md`, `H*.md`, `I*.md`, and `J*.md` files are historical change or finding
records. They document rationale and evidence, but do not grant release
approval. The current Alembic head is `0008_bot_store_bindings`; validation
scripts must use that revision.
